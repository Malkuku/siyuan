# 测试方案

## 现有验证层级

| 层级 | 入口 | 用途 |
|---|---|---|
| 前端类型与风格 | `app/package.json` 的 `lint` | 类型检查与 ESLint；该命令包含自动修复，执行后检查差异 |
| 前端回归 | `app/src/**/*.test.ts`、`app/tests/`、`app/electron/`、`app/scripts/` | 由 `pnpm test` 选择 Node 测试；具体文件是否被覆盖以脚本 glob 为准 |
| 独立契约 | `kernel/apicontract/` | 类型、schema、路由绑定与契约生成 |
| 内核行为 | `kernel/` 各包的 `*_test.go` | 模型、HTTP 响应、权限、兼容及存储回归 |
| 运行实例 | `siyuan-testing` 与手动 UI 验证 | 完整交互、跨端表现及真实集成；先读相关仓库规则 |

CI 实际选择以 [.github/workflows/cd.yml](../../.github/workflows/cd.yml) 为准。新增回归必须进入现有发现路径，或同步测试选择。

## 按变更选择最小充分验证

| 变更 | 工作目录 | 验证 |
|---|---|---|
| 仅 Spec 文档 | 仓库根目录 | 本地链接、路径、来源、状态与 Git 差异检查 |
| 前端行为 | `app/` | 定向行为回归与 `pnpm run lint`；需要全量时运行 `pnpm test` |
| Go 行为 | `kernel/` | 对变更文件执行 gofmt，运行受影响包及用例；涉及 SQLite 时参考下面的标签命令 |
| HTTP 契约 | `app/`、`kernel/` | API 生成与检查、lint、`go test ./apicontract/...`，以及实际响应、输入兼容和路由覆盖测试 |
| 翻译 | 仓库根目录 | `python scripts/check-lang-keys.py` |
| 加密与格式 | 受影响模块 | 支持的旧格式 fixture、认证失败、读写、导出、历史、备份、恢复与中断场景 |

内核全量回归入口为 `go test -tags "fts5 sqlcipher" ./... -count=1`，在 `kernel/` 执行。具体契约和权限测试选择见 [契约维护规范](../../docs/API-CONTRACTS.zh-CN.md)，按受影响范围使用其定向命令。

## 验收要求与限制

行为变更覆盖原始失败案例、真实消费入口、相邻边界与错误路径；类型检查不能替代行为回归。共享功能核对桌面、移动及共享依赖，平台专属变更说明适用边界。

浏览器验证打开运行内核的 `/stage/build/desktop/`。不运行 `npx webpack`、`pnpm dev` 或 `pnpm build` 作为验证，不编译内核二进制、不重启运行内核。运行实例及测试数据按 [仓库规则](../../AGENTS.md) 和测试仓库规则准备。

本次初始化只盘点测试入口，未执行业务测试，未评估所有模块的覆盖率。后续任务根据风险记录实际命令、结果、环境限制和未验证范围。
