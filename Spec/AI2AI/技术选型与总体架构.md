# 技术选型与总体架构

## 技术栈与运行入口

| 边界 | 来源 | 职责 |
|---|---|---|
| 桌面容器 | `app/electron/main.js`、`app/package.json` | Electron 主进程与桌面集成 |
| 主前端 | `app/src/index.ts` | 应用初始化与主 WebSocket 事件消费 |
| 分离窗口与移动端 | `app/src/window/`、`app/src/mobile/` | 平台入口与交互 |
| 编辑及导出渲染 | `app/src/protyle/`、`app/src/protyle/method.ts` | 块编辑器与独立渲染库 |
| 桌面内核 | `kernel/main.go`、`kernel/cli/cmd/` | CLI 与内核启动 |
| 网络服务 | `kernel/server/serve.go`、`kernel/api/router.go` | 资源服务、HTTP API、WebSocket 与其他协议入口 |
| 移动内核绑定 | `kernel/mobile/`、`kernel/harmony/` | 原生平台集成 |

前端采用 TypeScript、SCSS、webpack 和 pnpm；内核采用 Go、Gin、Lute AST 与嵌入式 SQLite。版本以 [app/package.json](../../app/package.json)、[kernel/go.mod](../../kernel/go.mod) 和 [CI 配置](../../.github/workflows/cd.yml) 为准。实际 Go 模块声明为 `github.com/siyuan-note/siyuan/kernel`。

## 模块责任

| 领域 | 主要实现 | 责任 |
|---|---|---|
| 笔记与编辑 | `app/src/protyle/`、`kernel/model/`、`kernel/treenode/` | 编辑交互、事务、树结构与领域行为 |
| 存储与索引 | `kernel/filesys/`、`kernel/sql/`、`kernel/search/` | 文件读写、数据库索引与搜索 |
| 数据库视图 | `app/src/protyle/render/av/`、`kernel/av/` | 属性视图渲染、布局、过滤和排序 |
| 应用交互 | `app/src/layout/`、`app/src/menus/`、`app/src/config/`、`app/src/mobile/` | 面板、菜单、设置与平台交互 |
| 外部契约 | `kernel/api/`、`kernel/apicontract/`、`app/src/util/fetch.ts` | HTTP 接入、传输类型与前端请求 |
| AI 与扩展 | `kernel/agent/`、`kernel/mcp/`、`kernel/plugin/`、`kernel/bazaar/` | Agent 运行时、MCP、插件与集市 |

前端通过 HTTP 提交请求，通过 WebSocket 消费推送；内核模型层承担业务规则，文件系统和索引层承担各自存储职责。新增行为应定位领域责任层及其全部消费入口，避免在单一 UI 入口重复实现业务语义。

## 数据与兼容边界

工作区布局见 [WORKSPACE](../../docs/WORKSPACE.zh-CN.md)，文档 AST 格式见 [SY-FORMAT](../../docs/SY-FORMAT.zh-CN.md)。加密笔记本的密钥、认证、历史、备份和恢复约束见 [ENCRYPTED-NOTEBOOK](../../docs/ENCRYPTED-NOTEBOOK.zh-CN.md)。派生索引仅能在源密文认证成功后重建。

HTTP 契约维护于 `kernel/apicontract/`，由生成器同步到前端与插件声明；接口接入规则见 [API 索引](API/README.md)。网络授权、租约与模型业务验证不能通过传输类型替代。

## 跨仓库与构建边界

`petal` 维护插件公开声明；`siyuan-testing` 维护运行实例的端到端测试；原生移动仓库维护平台封装。Lute 源码位于 Go 工作区的 `github.com/88250/lute`，本仓库的 `lute.min.js` 为上游构建产物。

禁止手改生成目录和打包二进制。前端验证使用 lint，不运行 webpack、开发或生产构建；修改 Go 后运行 gofmt，不编译内核二进制或重启内核。具体清单以 [AGENTS.md](../../AGENTS.md) 为准。
