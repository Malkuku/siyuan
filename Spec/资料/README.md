## 后续学习路线

以下内容尚未展开，按学习需要逐项整理。

1. 打开一篇文档：前端事件、HTTP 请求、内核处理与页面渲染

6. 开发运行：依赖安装、编译监听、内核启动和调试

每部分围绕一个具体问题展开，给出源码入口、解释和少量自查题。
