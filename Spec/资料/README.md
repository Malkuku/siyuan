## 后续学习路线

以下为学习顺序，可按自建项目需要调整；尚未展开的主题不计为已掌握。

| 顺序 | 主题 | 要能回答的问题与产出 |
|---|---|---|
| 1 | 块身份、文档树与引用 | 为什么需要稳定 ID？移动、删除、复制怎样影响引用？用数据示例和关系图说明 |
| 2 | 存储与检索 | 文件与索引分别负责什么？搜索、反向链接怎样得到结果？画出写入与查询的数据流 |
| 3 | 编辑操作与历史 | 更新、移动、删除、撤销分别改变哪些状态？整理操作前后状态与验收案例，复用已有保存知识 |
| 4 | AI Agent 协作边界 | Agent 怎样定位和修改内容？怎样处理重复操作、并发修改和结果确认？区分已有机制与自建方案 |
| 5 | 编辑器与应用边界 | 内容模型怎样对应可编辑界面？哪些职责属于编辑器、前端、内核和桌面容器？按实现需求补课 |

每轮围绕一个问题，先给数据示例或流程图，再讨论设计取舍，最后用具体场景检验理解。学习深度以能描述规则、识别失败情况并验收 AI 实现为准；关键规则需要时阅读短代码。打开文档调用链、Go 语法、Electron IPC、构建调试均按需展开。

思源机制作为参考事实；复刻首版范围、技术栈与课程计划由 kat-note 工作区维护。当前不预设完整复制思源功能。
