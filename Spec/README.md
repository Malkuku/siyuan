## 资料约定

- 项目学习笔记、架构说明和后续整理的学习资料统一放在 `spec/资料/`
- 学习资料索引维护在 [资料目录](资料/README.md)，新增内容时同步更新索引
- 资料以当前仓库源码为依据，区分已确认的实现与待研究的问题
- 修改已有结论时更新原文，避免堆积过期过程记录
- 功能开发规格后续按实际任务建立，不预先创建空模板
